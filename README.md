# Jack in the Jackrooms

A single-file HTML5 horror game. Play it at **https://dominodominick.com/jackinthejackrooms**.

The whole game is `index.html`. Push a new version to `main` and GitHub Pages republishes it within a minute or two.

## Versions

Every release is also saved in `versions/` as `jack_in_the_jackrooms_V<number>.html`.
`index.html` is always the latest version (it's what the website serves).

| Version | Changes |
|---|---|
| V20 | "JACK!" gang chant in the Jacknality theme; new Star Cannon ("Stardust") and N.O. Blade ("Edge of Time") finisher themes |
